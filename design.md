# MASTER X Design System

## Brand direction
Premium community operations: deep navy surfaces, dark teal, cyan, royal blue, emerald, and restrained purple accents. Use high contrast and clear hierarchy.

## Telegram message grammar
- Compact brand header and section title.
- One concise explanation per section.
- Consistent separators and emoji semantics.
- Success, warning, and danger states use distinct wording and symbols.
- Keep body text readable; Unicode display typography is decorative, never used for critical instructions or IDs.

## Navigation
Main menu categories: Group Settings, AI Assistant, Moderation, Anti-Spam, Analytics, Configuration, Help & Commands, Owner Panel. Show only options the current user can access. Include Back and Home controls and paginate long menus.

## Telegram constraints
Standard inline keyboard buttons do not offer arbitrary per-button background colors. Use supported button styles only where Bot API and client support them; use layout, emoji, text, and Mini Apps for visual hierarchy.

## Dashboard
Responsive web UI, group selector, clear active-tenant indicator, role-aware navigation, confirmation dialogs for destructive actions, audit history, accessible contrast, and mobile-first layouts.

## Artwork
Create original MASTER X assets with one coherent brand system. Do not reuse Rose/Combot/Iris logos or imply affiliation.
